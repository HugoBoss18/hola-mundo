# hola-mundo

Primeros pasos con Django.

## Requisitos

- Python 3.10+

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecutar el servidor

```bash
python manage.py runserver
```

Luego abre `http://127.0.0.1:8000/` para ver el mensaje inicial.

## Ejecutar pruebas

```bash
python manage.py test
```
